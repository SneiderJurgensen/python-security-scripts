# Python Security Scripts

Scripts de Python orientados a ciberseguridad, automatización y análisis.

## Estructura

```
python-security-scripts/
├── scripts/
│   ├── scanner/          # Scripts de escaneo
│   ├── automation/       # Automatización de tareas
│   └── utils/            # Utilidades comunes
├── docs/                 # Documentación adicional
└── requirements.txt
```

## Categorías

| Carpeta       | Descripción                              |
|---------------|------------------------------------------|
| `scanner/`    | Escaneo de puertos, redes, servicios     |
| `automation/` | Automatización de tareas de seguridad    |
| `utils/`      | Funciones reutilizables y helpers        |

## Requisitos

```bash
pip install -r requirements.txt
```

## Uso

Cada script incluye su propia documentación en comentarios o README interno.
